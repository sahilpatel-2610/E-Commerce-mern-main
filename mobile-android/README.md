# Vraj Creation - Native Android App

Standalone Native Android E-Commerce Application built with **Kotlin, Material 3, OkHttp, Glide & Firebase Firestore REST API**.

## Architecture & Features
- **Direct Live Firestore Integration**: Connects directly to Firestore documents for Products, Hero Banners, and Orders.
- **Luxury Theme**: Vraj Creation bespoke gold and dark aesthetic with Material 3 styling.
- **RecyclerViews & Image Caching**: High-performance image loading with Glide and responsive grids.
- **Complete User Flow**:
  - Home Showcase with Live Banners, Best Sellers, and Latest Collections
  - Searchable & filterable Shop Catalog
  - Product Details screen with discount badges and description
  - Dynamic Shopping Bag with quantity management and Cash-on-Delivery Order placement
  - Account/Profile overview

## How to Run in Android Studio

1. Open **Android Studio**.
2. Click **File -> Open...** and select the `mobile-android` folder:
   `d:\E-Commerce-mern-main\mobile-android`
3. Wait for Gradle Sync to finish.
4. Connect an Android device (via USB with Developer Options / USB Debugging enabled) or start an Android Emulator.
5. Click the green **Run (Shift + F10)** button in Android Studio.
