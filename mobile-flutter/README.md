# Vraj Creation - Flutter Mobile App

Luxury Bespoke Menswear Mobile E-Commerce App built with **Flutter & Firebase Firestore**.

## Features
- **Live Firebase Firestore Integration**: Dynamic products, hero video/image banners, categories, and real-time order creation.
- **Bespoke Luxury UI**: Custom dark & gold palette tailored for high-end fashion e-commerce.
- **Bottom Navigation**: Home, Collection (Filter & Search), Shopping Bag with live badge, Account.
- **Shopping Bag**: Size/Color selection, dynamic subtotal & delivery calculation, Firebase order placement.

## How to Run on Mobile / Emulator

### Prerequisites
1. [Flutter SDK](https://docs.flutter.dev/get-started/install) installed.
2. Android Studio with an Android Emulator or physical device connected via USB with Developer Mode & USB Debugging enabled.

### Steps to Run:
```bash
# 1. Navigate to flutter project directory
cd mobile-flutter

# 2. Get dependencies
flutter pub get

# 3. Check connected devices
flutter devices

# 4. Run the app
flutter run
```
